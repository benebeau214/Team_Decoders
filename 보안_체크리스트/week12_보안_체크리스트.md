# AI 데이터 보안 체크리스트

- 검토 주차: 12주차

## 체크 항목

1. 제출물에 실존 인물의 실명·전화번호·이메일 등 PII가 포함되지 않았다. (o)
   - 프로젝트 데이터는 가상 브랜드와 가상 재무·공시 자료를 사용한다.
   - 개인정보를 수집하거나 저장하는 로그인·회원 기능을 포함하지 않는다.

2. 외부 AI(챗봇·API)에 기업 기밀·타인 코드·PII를 입력하지 않았다. (o)
   - 현재 [llm_client.py](../llm_client.py)는 데모용 mock 응답을 기본으로 사용한다.
   - 외부 LLM API 호출 기능은 구현되어 있지 않으므로 PII나 기업 기밀을 외부에 전송하지 않는다.

3. 외부 데이터 사용 시 출처·라이선스를 확인하고 PII 열을 비식별 처리했다. (o)
   - 업로드 데이터는 팀이 준비한 공개 공시 기반 데모 CSV를 사용한다.
   - 데이터셋에 실존 인물 정보 또는 PII 열을 포함하지 않았다.

4. API 키·비밀번호가 소스코드에 하드코딩되어 있지 않다. (o)
   - API 키와 비밀번호는 소스코드에 직접 작성하지 않는다.
   - 현재 mock 모드이므로 저장소에 API 키가 필요하지 않다.

5. `.env` 파일이 `.gitignore`에 등록되어 있고, `git ls-files` 확인 결과 추적되지 않는다. (o)

6. 커밋 히스토리에 키가 노출된 적이 없다. 노출 시 폐기·재발급 완료를 명기한다. (o)

7. 키·비밀 값을 print/log/스크린샷으로 전체 출력하지 않았다. (o)
   - [llm_client.py](../llm_client.py)는 환경변수에서 `USE_MOCK`만 읽는 구조를 사용한다.
   - 키 또는 비밀 값을 화면, 로그, 테스트 결과에 출력하지 않는다.

8. AI 사용 내역(프롬프트·채택·수정)을 과제 규정에 따라 기록·첨부했다. (o)
   - 프롬프트 템플릿은 `prompts/` 폴더에 정리되어 있다.
   - 교차 리뷰와 AI 사용 기록은 저장소의 `ai_log/` 및 관련 문서에 기록되어 있다.

9. (LLM 기능 포함 시) 사용자 입력 검증과 출력 검증(형식 확인)을 적용했다. (o)
   - 입력 검증:
     - 보증금·권리금·대출금은 0 이상으로 제한하고 대출 금리는 0~100 범위로 제한한다.
     - CSV 업로드는 필수 파일명과 필수 컬럼을 검증하고, UTF-8·CP949 인코딩을 지원한다.
     - 중복 업로드와 누락 파일을 사용자에게 안내한다.

   - 출력 검증:
     - [franchise_checkup/llm_tasks.py](../franchise_checkup/llm_tasks.py)는 LLM 응답의 JSON 형식과 필드 타입을 확인한다.
     - 특수관계자 거래와 불리한 계약 조항의 원문 인용이 원본 텍스트에 실제로 존재하는지도 검증한다.
     - 현재는 mock 응답을 사용하므로 외부 API의 실제 응답 검증은 수행되지 않았다.

10. (LLM 기능 포함 시) 시스템 프롬프트에 비밀 정보를 포함하지 않았다. (o)
    - 시스템 프롬프트와 작업 프롬프트에는 API 키, 비밀번호, 개인 정보 등을 포함하지 않는다.
    - 프롬프트에는 분석 대상 텍스트와 결과 형식만 전달한다.
